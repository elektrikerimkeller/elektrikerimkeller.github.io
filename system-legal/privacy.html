2. Über den Dienst

System Bot ist ein unabhängiger Discord-Bot mit einem zugehörigen Web-Dashboard. Der Dienst stellt verschiedene Funktionen für Discord-Nutzer und Discord-Server bereit.

Für bestimmte Funktionen ist eine Anmeldung bzw. Autorisierung über Discord OAuth2 erforderlich.

Hinweis: System Bot ist ein unabhängiger Drittanbieterdienst und steht nicht in Verbindung mit Discord Inc., sofern nicht ausdrücklich anders angegeben.

3. Welche Daten werden verarbeitet?

3.1 Discord-Daten

Im Rahmen der Discord-Autorisierung können abhängig von den angeforderten OAuth2-Berechtigungen insbesondere folgende Daten verarbeitet werden:

  • Discord User ID
  • Discord Benutzername bzw. Anzeigename
  • Discord Server-/Guild-Informationen
  • von Discord bereitgestellte Accountinformationen
  • E-Mail-Adresse

3.2 Dashboard-Daten

Für das Web-Dashboard können zusätzlich folgende Daten verarbeitet werden:

  • E-Mail-Adresse
  • Discord User ID
  • Login- und Sitzungsinformationen
  • technische Informationen
  • IP-Adresse, soweit technisch erforderlich

4. Zweck der Verarbeitung

Die Verarbeitung erfolgt insbesondere für:

  • Authentifizierung über Discord
  • Bereitstellung des Web-Dashboards
  • Verknüpfung des Discord-Accounts mit dem Dashboard
  • Bereitstellung von Accountfunktionen
  • Betrieb und Wartung des Bots
  • Schutz vor Missbrauch und unbefugtem Zugriff
  • Sicherheit und Stabilität des Dienstes
  • Erfüllung gesetzlicher Verpflichtungen

5. Discord OAuth2

Für die Anmeldung verwendet System Bot Discord OAuth2. Während des Autorisierungsvorgangs werden die vom Nutzer freigegebenen Informationen an unseren Dienst übermittelt.

System Bot erhält und speichert kein Discord-Passwort.

Weitere Informationen zur Datenverarbeitung durch Discord findest du in der Datenschutzerklärung von Discord .
